Accordions

Sections that open one at a time, or each on its own, on the browser's own disclosure - <details> and <summary>: no script, the keys and the open state built in, and the browser's find in page opens a closed section on a match.

Examples

Items that share a name are one group: opening one closes the one that was open. open opens an item from the start.

The transfer from the hotel, the boat, lunch, snorkelling gear and the park fee.

Free of charge up to 24 hours before the start; later, half the price is kept.

From four years old; under four they travel free.

Contents from the server

An element with data-lazy - a details or its accordion-body, a region a --toggle button opens, a tab panel, a tree's group, a popover or a dialog or a region in one - fires redz:load on itself with {region} the first time it shows: open at load, put in open later, or opened by a person, never for the paper. The library takes data-lazy away first. A page that loads the contents cancels the event and answers with a promise by event.detail.respondWith: meanwhile an empty region shows three placeholder lines and, to a screen reader, the page's text busy. A refusal puts data-lazy back and shows its words in the region, which stays open; the next opening tries again. Writing data-lazy again on a region that shows - its contents are stale - loads it again at once.

History of changes 
document.addEventListener('redz:load', (event) => {
	if (event.target.id !== 'history') {
		return;
	}
	event.preventDefault();
	event.detail.respondWith(fetch('/excursions/12/history')
		.then((answer) => answer.ok ? answer.text() : Promise.reject(new Error('The history could not be loaded.')))
		.then((html) => {
			event.detail.region.innerHTML = html;
		}));
});

Keyboard and accessibility

KeyOn a section's header
Enter, SpaceOpens or closes the section; in a group, opening it closes the open one
TabThe next header, or the first control inside an open section
  • The header is the <summary> itself, which the browser announces as expanded or collapsed. Put no heading inside it: screen readers announce a heading in a summary unevenly. When the sections need a place in the page's outline, a heading goes before the accordion.
  • The chevron is decoration, aria-hidden="true"; it turns as the section opens.
  • A section opens with a short animation only where the browser has interpolate-size, and only when the reader allows motion; elsewhere it opens at once.
  • From script: details.open = true, and the toggle event after each change.
