Chips

A chip is a small rounded choice: a filter that is on or off, a saved view, an applied filter with its count and a way to remove it.

Examples

A filter chip is a toggle button: aria-pressed says whether it is on. A chip that opens a menu is the menu's button.

Saved views and applied filters

Links between saved views mark the current one with aria-current="true". An applied filter is a group: its name, its count in chip-count, and a chip-dismiss button named after what it removes.

Keyboard and accessibility

  • A filter chip is a <button> with aria-pressed; Space or Enter toggles it. Change the attribute when the filter changes — the look follows it.
  • A saved view is a link; the current one carries aria-current="true".
  • An applied filter is role="group" named after the filter, and its dismiss button names what it removes — "Remove filter: section Marine", not "Remove".
  • A count is part of the chip's name; say what it counts in the words around it when it is not obvious.
