Collapse

A button that opens and closes a region elsewhere on the page - help under a toolbar, more filters, the details of a row - by the library's own command, --toggle. A closed region is hidden="until-found", so the browser's find in page still reaches its words and opens it. A section that opens under its own header is an accordion.

Examples

The button carries command="--toggle", names its region in aria-controls and says in aria-expanded whether the region is open: write it as the region starts, and the library keeps it. It takes no commandfor: WebKit would then tell a screen reader the button is collapsed whatever its aria-expanded says.

Open from the start

A region without hidden starts open, its button aria-expanded="true".

A details row in a table

A row under a row opens and closes the same way: the region is a <tr> with one cell across the table. A table's row cannot be hidden "until found", so it starts as plain hidden and closes so again; find in page does not open it.

Keyboard and accessibility

KeyOn the button
Enter, SpaceOpens or closes the region; every button for it says the new state
  • Find in page opens a closed region on a match where the browser has hidden="until-found" - Chrome, Firefox 148 and Safari 26.2 on - and the library marks its buttons open; in older browsers the region stays closed until its button opens it.
  • Put the region right after its button in the reading order, or name it, so a reader who opens it finds it.
  • From script: region.hidden = false opens it - set aria-expanded on its buttons yourself then.
