Commands to copy

A command a person runs on their own machine - an install line, a crontab entry, a request with a key - shown on one line, copied whole by one button.

Examples

command-line is one frame: a pre tabindex="0" translate="no" holding a code, and a --copy button in its own column. The command stays on one line, left to right on any page, and scrolls sideways under a fade at the cut edge - never under the button; a click selects it whole. The button without aria-controls copies its command. The words above name it: the box is role="group" with aria-labelledby, as a pre may carry no name of its own.

Add this line to the server's crontab:

*/5 * * * * php /var/www/example/cron.php --task=maintenance --quiet >> /var/log/example-cron.log 2>&1

A var in the command is a part the person puts in themselves - a key, a host - and shows as an amber chip. A page that fills it later, on a reveal, writes plain text in its place.

Ask for the bookings of today:

curl -H "Authorization: Bearer YOUR_KEY" https://api.example.com/v1/bookings?day=today

Steps

ol class="command-steps" numbers commands run one after another, each step a line of words and its command-line, in circles joined by a line. A --copy button whose aria-controls names the list copies all its commands, a line each. Commands that are alternatives - one or the other - go in a plain vstack instead.

Install the agent

  1. Download it:

    curl -fsSLO https://get.example.com/agent/agent-2.4.tar.gz

  2. Unpack it:

    tar -xzf agent-2.4.tar.gz -C /opt

  3. Start it:

    /opt/agent/start --key YOUR_KEY

Accessibility

  • The command is a tab stop, so a keyboard scrolls it; its words above it name the group.
  • The copy button says what it copies in its name and says politely that it did, in the page's texts copy.done and copy.failed.
  • translate="no" keeps a page's translator from turning the command into words.
