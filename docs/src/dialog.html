Dialogs

The browser's own modal <dialog>: opened by a command, the page behind it inert and dimmed, closed by its buttons, Esc or a click outside. And REDZ.ui.confirm() for a question asked from script.

Examples

A button opens the dialog with commandfor + command="show-modal"; buttons inside close it with command="close". closedby="any" lets a click outside close it too. The focus goes into the dialog — to the control marked autofocus — and back to the button when it closes.

A note for the guides

Sizes

dialog-sm for a question, the default for a form, dialog-lg for a wide table or a preview.

A confirmation from script

await REDZ.ui.confirm({title, text, ok, tone}) builds an alertdialog, waits for the answer and removes it: true for the confirming button, false for Cancel, Esc or a click outside. The focus starts on Cancel; the button words come from the caller or the page's texts.

Keyboard and accessibility

  • Tab stays inside an open dialog; Esc closes it; the focus goes back to the button that opened it.
  • The dialog is named by its title through aria-labelledby. A question that must be answered is role="alertdialog" with its focus on the safe answer.
  • The page behind does not scroll while a dialog is open, and keeps its width: the scrollbar's place stays.
  • A notice raised while a dialog is open shows inside the dialog, since everything outside it is inert.
  • Where the browser lacks invoker commands (below Chrome 135, Firefox 144, Safari 26.2) or closedby (below Chrome 134, Firefox 141, and in Safari), the library's script stands in.
