Empty states

What a list, a panel or a search shows when it has nothing yet: what would be here, and the one action that starts it. And the drop zone of a file field.

Examples

No excursions yet

An excursion is a page with a price, a schedule and a booking form.

A drop zone

empty-state-drop is a label around a hidden file input: a click or a dropped file goes to the input.

States

classrest:hover
empty-state-drop

Accessibility

  • Say what would be here and why it is empty — "No excursions yet", "Nothing matches the filters" — and offer the action that changes it.
  • The drop zone's file input is hidden visually only; its label is the zone's words, and the focus ring shows on the zone through the label.
