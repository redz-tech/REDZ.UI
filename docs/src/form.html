Form fields

Text fields, selects and text areas with Bootstrap 5's names: a label floating in the field or above it, a hint, an error said in words, an icon inside the field.

Examples

form-floating keeps the label inside the field and lifts it when the field has a value or the focus. The label follows the control, and the control needs a placeholder — it is how CSS knows the field is empty.

A label above, a hint, an error

form-field stacks a field's parts: form-label, the control, form-text for a hint and invalid-feedback for an error. The control points at both with aria-describedby; an error sets aria-invalid="true", and the browser's own :user-invalid draws the same after the person has edited the field.

Keyboard and accessibility

  • Every control has a visible label: a <label for>, or aria-label only where the context says it all — a search field with its icon.
  • A placeholder is never the label: it goes away as the person types. In form-floating the placeholder is only the empty marker.
  • An error is said in words in invalid-feedback, joined to the control by aria-describedby; a color alone never tells it.
  • The borders of fields and the focus ring are at least 3:1 against the page in both themes; the text 4.5:1.
  • form-select paints its own chevron from the theme, mirrored right to left; a multiple select or one with size drops it.
