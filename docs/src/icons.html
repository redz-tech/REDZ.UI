Icons

Bootstrap Icons 1.13.2 under their own class names — <i class="bi bi-pencil"> — each a CSS mask over its own SVG file: the color of the text around it, no font, no script, no build.

Examples

An icon takes the size of the text and its color: a utility or the parent sets both.

The names are Bootstrap Icons' own — look one up at icons.getbootstrap.com. A name the set does not have paints a filled square, and the checks flag it.

Accessibility

  • An icon beside words is aria-hidden="true". An icon alone takes its meaning from its parent: the button's aria-label, or hidden words.
  • Icons that point — chevrons, arrows, back and next — mirror right to left with flip-rtl; a check, a clock, a search glass, media controls do not.
  • Icons keep the forced color of their parent and print in their color.
