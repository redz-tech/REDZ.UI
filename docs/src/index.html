Getting started

REDZ.UI is two stylesheets and a set of small scripts on the browser platform. Nothing is built where it is used: link the files, write Bootstrap-like markup, and the browser does the rest.

Include it

The stylesheet, the icons and the scripts, with the page's own words for the few things the library says — every word comes from the page, the library has none of its own.

<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <link rel="stylesheet" href="redz-ui/css/index.css">
  <link rel="stylesheet" href="redz-ui/css/icons.css">
  <script type="module" src="redz-ui/js/index.js"></script>
  <script type="application/json" id="redz-ui-text">{"close": "Close", "confirm.ok": "OK", "confirm.cancel": "Cancel", "busy": "Loading…"}</script>
</head>
  • css/index.css pulls in the layers, the tokens, the components and the utilities, 19 KB gzipped. A consumer that bundles may join its files in that order.
  • css/icons.css is apart: one mask per Bootstrap Icons file, used only by name.
  • js/index.js is an ES module; it loads the behaviors and sets REDZ.ui for calls from code.

How it reads

  • A component, its variant, its size and its parts are one class each: btn btn-primary btn-sm, card-header — Bootstrap 5's names, and Bootstrap 6's where it moved onto the platform: dialog, drawer, menu.
  • A utility is property-value: d-flex, text-muted. The number is the value — p-16 is 16 px, w-50 is 50 %.
  • A condition is a prefix: md:cols-2, print:d-none. A width prefix measures the region the element sits in — a column, a card, a dialog — not the window.
  • A state is an HTML attribute: aria-pressed, aria-current, disabled, [open]. A button opens a menu or a dialog with the browser's own command: commandfor + command.
  • Tokens are --redz- plus the same words: --redz-text-muted, --redz-space-16.

Theme and direction

Without an attribute the page follows the system's light or dark. data-theme="light" or data-theme="dark" on <html> fixes one — set it on the server, so the page never flashes. Right to left is dir="rtl": one stylesheet serves both directions, by logical properties, and icons that point mirror with flip-rtl.

<html lang="ar" dir="rtl" data-theme="dark">

From script

Menus, tabs, dialogs and their keys need no call: the library listens on the document. Three calls are for code:

CallDoes
REDZ.ui.toast({title, text, tone, action, persistent})Shows a notice; answers a function that closes it. Toasts
await REDZ.ui.confirm({title, text, ok, cancel, tone})Asks a question in a dialog; answers true or false. Dialogs
await REDZ.ui.busy(element, promise)Marks a button or a region busy until the promise settles. Busy

Browsers

Bootstrap 6's floor: Chrome and Edge 130+, Firefox 132+, Safari 18+ on macOS and iOS. What must work rests on features of the floor; invoker commands and anchor positioning are written in their final form, and a small script stands in below them. Every page of these docs is checked in real engines at the floor and above — the checks.
