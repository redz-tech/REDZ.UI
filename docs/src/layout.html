Layout

The parent sets the grid, the number is the count, and a width prefix measures the region the element is in. Stacks for a column or a row of items, gaps between them, no margins on components.

Grids

grid on the parent, cols-N for N equal columns, gap-* between them. A width prefix adds columns as the region grows: grid md:cols-2 is one column until the region is 768 px wide. Every example on these pages is a region of its own — resize the window and watch the examples, not the window.
