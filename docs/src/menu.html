Menus

A menu is a short list of actions or choices that opens from a button: the browser's popover, placed beside the button by CSS anchor positioning, driven by the keyboard as the WAI-ARIA menu button.

Examples

The button opens the menu with the browser's command — commandfor names the menu, command="toggle-popover" opens and closes it — and the browser sets its aria-expanded. No script is needed to open a menu; the library adds the arrow keys.

Open on the site

Choices and headers

A choice of one is a set of menuitemradio items, the chosen one aria-checked="true" with a check drawn after it. menu-header titles a part of the menu. menu-start lines the menu up with its button's start edge instead of its end.

  • The menu is popover with role="menu" and a name; its items are menuitem, menuitemradio or menuitemcheckbox. A list of site sections is navigation, not a menu — use links.
  • The button carries aria-haspopup="menu"; the browser keeps its aria-expanded, moves the focus back to it on close and closes the menu on a click outside or Esc.
  • Where an engine does not put the menu beside its button — no anchor positioning below Firefox 147 and Safari 26, no anchor from a popover's button in Chrome 130–132, a table cell in Chrome 135–136, the bottom of a long page in Safari 26 — js/menu-place.js places it, and the probes record each such place.
