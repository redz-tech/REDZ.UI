From Bootstrap 5.3

Most of Bootstrap 5's names stay. What changes is the spacing numbers, the grid, the breakpoints, states and triggers, and the three components Bootstrap 6 renamed. The two libraries are never on one page: a project switches its stylesheet at once.

What changes

  • Spacing: the number is the pixels. p-3 becomes p-16, mb-2 mb-8, gap-4 gap-24 — and p-4 exists in both with another size: Bootstrap's 24 px, REDZ.UI's 4 px. Never rename by chained replacements; rewrite each file once.
  • Grid: row and col-md-6 become the parent's grid md:cols-2; a column's own width is span-N.
  • Breakpoints: the infix becomes a prefix — d-md-none is md:d-none — and it measures the region, not the window.
  • States: classes become attributes — .active is aria-current, aria-selected or aria-pressed; .disabled is disabled or aria-disabled; .is-invalid is aria-invalid="true".
  • Triggers: data-bs-toggle becomes the browser's commands — commandfor + command="show-modal", "close" or "toggle-popover"; bootstrap.Modal becomes dialog.showModal().
  • Renamed: modal → dialog on a <dialog>, dropdown → menu on a popover, offcanvas → drawer.
  • Icons: Bootstrap Icons keep their classes; swap the font's stylesheet for css/icons.css.

With an agent

The skill redz-ui-from-bootstrap-5 moves a project file by file: scripts/scan.sh finds every Bootstrap class, attribute and call with its replacement and checks every class against the vocabulary; the agent rewrites the whole file in one pass, scans it again until nothing is left, and compares the screens before and after. Install it with npx skills add redz-tech/REDZ.UI.

The map
