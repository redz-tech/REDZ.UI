Tabs

Tabs switch panels in place: role="tablist", each tab role="tab" with aria-selected and aria-controls, each panel role="tabpanel". The library keeps only the selected tab in the tab order and only its panel shown. The arrow keys select as they move.

Tabs whose panels load

When a panel comes from the server, the arrows should not load every panel they pass: data-activation="manual" on the tablist makes them move the focus only, and Enter or Space selects.

  • Links that change the page are a <nav> of links, never tabs: tabs only switch what is already on the page.
