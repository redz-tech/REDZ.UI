Pagination

Links to the pages of a long list, with Bootstrap's names: the current page says so in aria-current="page", a page there is none of says so in aria-disabled. A list that pages by "the next 50" shows only previous, next and where you are.

Examples

A nav named for what it pages holds the list; each page is a link. A page there is none of - the previous one of the first page - is a link without href and aria-disabled="true", out of the Tab order. Skip no page silently: an ellipsis stands for the pages between. Show no pagination for a single page.

Keyboard and accessibility

  • The nav has a name - "Pages of excursions" - so a screen reader lists it among the landmarks; the current page is aria-current="page", read as "current page".
  • An arrow-only link carries its words in visually-hidden text; the chevrons turn round right to left by flip-rtl.
  • A page there is none of has no href, so Tab passes it, and aria-disabled="true" greys it.
