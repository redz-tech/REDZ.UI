Command palette

One search for every place and action of an app, opened from anywhere by ⌘K or Ctrl K: a dialog with the combobox's search and a list of links and buttons - Enter opens a page by its plain link or runs a button's command.

Example

The button opens the dialog by the browser's command and names its keys in aria-keyshortcuts, which the library also takes as the shortcut. The options are links and buttons with role="option", in groups; the search finds them by their words and by data-keywords.

Shortcuts

A button or a link whose aria-keyshortcuts names a combination with Control, Meta or Alt is pressed by it: the page states the keys once, for screen readers and for the library. Where both Meta+K and Control+K are named, Apple's systems answer ⌘K and the others Ctrl K, so Control K keeps its meaning in a Mac's text fields; Firefox's own Ctrl K gives way to the page's.

  • A single key is never a shortcut here: WCAG 2.1.4 asks for a way to turn such keys off, and a combination needs none.
  • A disabled, hidden or inert button is left alone, and so is one outside an open modal dialog. Its combination is still the page's and never reaches the browser, so a save button that is busy or has nothing to save keeps Ctrl S from the browser's own save. The first that can be pressed now is pressed.
  • A combination held down presses once; its repeats are kept from the browser.
  • The hint the button shows - ⌘K or Ctrl K - is the page's to write.

  • The palette is a modal <dialog> with a name; a click on its backdrop closes it (closedby="any"). Opening it empties its search.
  • Its search is the WAI-ARIA combobox with a listbox, as in Combobox: the options are plain links and buttons with role="option", so a link opens in a new tab with ⌘ or the middle button as any link does. The library keeps them out of the Tab order (tabindex="-1"): the arrow keys reach them, as in every listbox.
  • Where the options come from - the app's menu, recent pages, a search on the server - is the page's: a server search answers redz:search as a combobox's does.
