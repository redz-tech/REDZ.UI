Redrawn regions

A region the page draws again - a list it asks the server for every few seconds, a card after a change - keeps what the person was doing in it. REDZ.ui.swap() waits while a menu is open in the region, puts the new content in, and carries the filter, the sort, the search, the ticked rows, the open parts, the scroll and the focus over by id. A part that did not change stays as it is, its menu open.

Examples

Type in the search, press Online, sort by Load, tick a row, open the maintenance window, scroll the table sideways, open a row's menu - then redraw. Each redraw changes one server's load: the other rows stay as they are, and a menu open in one of them stays open. A menu open in the changed row holds the redraw until it closes.

The page asks its server, makes nodes of the answer and hands them over; the library makes no request and parses no string. A <template>, a DOMParser document or a request with responseType = 'document' make the nodes - under Trusted Types that parse is the page's own, through its policy, or the page hands over the policy's TrustedHTML as it is.

const answer = await (await fetch('/servers/list')).text();
const template = document.createElement('template');
template.innerHTML = answer; // or policy.createHTML(answer) under Trusted Types
await REDZ.ui.swap(document.getElementById('swap-servers'), template.content);

What is carried over

The new content is the server's; what the person set in the old content is set again in the new one, matched by id. Give the parts ids: rows, tables, scroll boxes, toggled regions, the buttons that open menus by commandfor.

A search's words (data-filter) and the words of the focused fieldThe field's id; a field of a tracked form is never written

The scroll of the region and of its scroll boxesThe box's id, else its place among the region's .table-scroll

The focus and a field's caretThe id; else the button with the same commandfor, or the same aria-controls and command; else a field with the same name and value; else the first control of the nearest part with an id; else the region itself

Not carried: pages a "show more" list loaded, which are data - ask the server for as many - and anything the page set by its own script, which redz:swap lets it set again.

When it waits

A swap goes in at once when nothing in the region is in use. It waits while what it would take out holds a menu, a popover or a dialog that is open - or one opened from a button in it - a tracked form with changes, or words being composed with an input method, and tries again as each of those ends: no timer. A newer swap of the same region overtakes a waiting one, which answers false; so does an aborted signal. Typing in a field does not hold a swap: its words, caret and focus are carried.

Elements with an id are parts. A part whose new copy is equal to the copy the last swap brought - the first time, to the part as it stands - stays as it is: its menu open, its spinner turning, its focus. Where the browser moves a node alive (moveBefore: Chrome 133, Firefox 144) such a part never holds a swap; elsewhere, Safari among them, it is moved as any node is and holds the swap like the rest.

From code

Call or eventWhat it does
REDZ.ui.swap(region, source, {signal})Puts the source's content into the region; a promise of true once it is in, false when a newer swap overtook it or the signal aborted. source is a DocumentFragment, a Document, an Element or a TrustedHTML; when it holds an element with the region's id, that element's children are taken, else all of it. Its scripts are dropped, its nodes taken.
REDZ.ui.swap(source, {signal})Puts each top element of the source that has an id into its namesake on the page - a card's head and its regions from one answer. A promise of true when every one went in.
redz:swapFired on the region, bubbling, once the new content is in and carried over: the moment for the page's own setup of it.

Keyboard and accessibility

  • The focus stays where the person was: on the same control, or on its nearest namesake. When the row it was on is gone, the region takes it - made focusable with tabindex="-1" - so the next Tab goes on from there, not from the top of the page.
  • A swap says nothing aloud. A list that changes under a person's eyes - new rows, a state that turned - is for the page to say, in its own words, with a status line or a toast.
  • Redraw no faster than people read: every few seconds at most, and not while nothing changed.
