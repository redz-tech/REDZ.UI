Message threads

A conversation in a card: each message with its author, time and files, the person's own at the end in a tint, the other side's at the start - edited in place, the reply box held under the thread.

Example

ol class="thread" of thread-messages; data-mine puts the person's own at the end in a tint. A message holds an avatar and thread-body: thread-meta - the name, a time, thread-edited and the message's buttons -, thread-bubble, which keeps its line breaks, and thread-files - thumbnails up to 9rem × 7rem, each with a thread-file-remove that shows while the message is edited. Editing is an inline edit: the form takes the bubble's place. In a card card-scroll with a height the thread scrolls between the card's header and its footer, which holds the reply.

Accessibility

  • The thread is a list with a name; each message starts with its author and time in words, so the side is never told by place or tint alone.
  • A file's thumbnail has the file's own alt; its remove button is named by the file.
  • The scrolling body of a card is reached by Tab through its buttons and links; give it tabindex="0" and a name when it holds none.
