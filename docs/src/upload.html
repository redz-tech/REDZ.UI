File upload

Photos, documents, a price list: chosen, dropped or pasted, each file checked at once and sent on its own, with its own progress and its own error.

Examples

upload holds the file input, an upload-zone button that opens it and takes files dropped on it, a <template> of one file's row and an upload-list. A paste while the focus is in the upload takes the clipboard's files. Each file is checked against the input's accept and the upload's data-max-size in bytes; a refusal shows in the file's row, the page's text file.type or file.size. A file dropped beside the zone does not open in the window.

    Sent by the page

    Each file fires redz:files on the upload with the file, its row, progress(fraction) for the row's bar and a signal its remove button aborts. A page that sends cancels it and answers with a promise: resolved, the row is done; rejected, the page's words show in the row's data-file-error. One file's error leaves the others. Left alone, the file joins the input's files and goes with the form. The example above answers in a second and a half.

    document.addEventListener('redz:files', (event) => {
	event.preventDefault();
	const {file, progress, signal} = event.detail;
	event.detail.respondWith(new Promise((sent, failed) => {
		const request = new XMLHttpRequest();
		request.open('POST', '/files');
		request.upload.onprogress = (step) => progress(step.loaded / step.total);
		request.onload = () => (request.status === 200 ? sent() : failed(request.responseText));
		request.onerror = () => failed('The file did not arrive');
		signal.addEventListener('abort', () => request.abort());
		request.send(file);
	}));
});

    Keyboard and accessibility

    • The zone is one real button: Enter or Space opens the browser's picker; the input itself stays out of the Tab order, and its words — which follow the browser's language, not the page's — never show.
    • A refused or failed file says why in its row, at once; a removed file's focus goes to the next file's remove button, else to the zone.
    • Each remove button is named after its file, from the page's text remove.
