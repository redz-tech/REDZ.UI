REDZ.UI

The interface library of the REDZ products: plain CSS and small JavaScript on the browser platform — no framework, no build step.

In design · nothing released yet Source on GitHub

The approved prototype of the look. A switch at the bottom of each screen turns the system, light and dark themes, left-to-right and right-to-left, and the compact density.

What it is

  • Tokens, a reset, cascade layers, components and a short set of utilities, written as plain CSS files.
  • Behaviour of the widgets that the platform does not give by itself — menus and tabs by keyboard, toasts, a combobox — as small JavaScript that attaches by delegation.
  • Light, dark and system themes; left-to-right and right-to-left from one stylesheet; WCAG 2.2 AA in both themes.
  • A static reference of every component in every state, checked in Chrome, Safari and Firefox.

Icons

Bootstrap Icons 1.13.2, one SVG file per icon. Each icon will be a CSS mask over its file — the color of the text around it, no font, no JavaScript, no build (decided; it lands with the base):

<i class="icon icon--pencil" aria-hidden="true"></i>

Browsers

Released since January 2026: Chrome and Edge 135+, Firefox 147+, Safari 26.2+ on macOS and iOS.

Nothing is written for older browsers; newer features only as enhancements.
